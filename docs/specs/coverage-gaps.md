# Сверка покрытия: что делает ванильный сервер 26.3 и чего нет в плане и коде

Статус: черновик, роль Reader. Источник: `reference/26.3/server-src/` (только чтение).
Текст написан своими словами; имена классов и методов не переносятся, только протокольные
и форматные имена (команды, ключи файлов, id пакетов).

**Метод.** Прошёл пакеты верхнего уровня, `server/*`, `world/*`, `util`, `core`, `stats`,
`advancements`, `commands`, `gametest`. Для каждого пакета выписал возможности по именам
его содержимого и по числовым константам. Проверил по `docs/ROADMAP.md` (поиск по русским
и английским ключевым словам) и по `crates/` (поиск по именам возможностей и по строковым
литералам команд).

**Оговорка.** «Нет в crates» значит «поиск не нашёл», это может быть ложный минус. Перед
реализацией Writer проверяет по коду. Фазы — из `docs/ROADMAP.md`: Ф0–Ф12, Ф6½, «Платформа».

**Легенда.** «План» — упомянуто ли в ROADMAP: **да / частично / нет**. «Код» — есть ли
что-то в `crates/`: **да / частично / нет**.

---

## 1. Верхний уровень `server` (запуск, тик, управление сервером)

- **Управление скоростью тика** (команда `/tick`): задать темп тика, заморозить мир,
  сделать один шаг тика, «спринт» — прогнать N тиков без задержки и ответить после. Тик
  ванили меряет тики, которые реально прошли. Фаза: Ф3 (тик), команда в Ф6. План: нет.
  Код: частично (есть только запрос тика).
- **Ссылки сервера и серверные уведомления в консоли.** Ссылки — Ф6, план есть. Код: нет.
- **Режим GUI-окна сервера** (список игроков, график TPS, память). Нам не нужен, но надо
  решить: вывод в консоль или в лог. Фаза: Ф6, решение владельца. План: нет.

## 2. `server/chase` — внешняя трансляция позиции игрока

- Сервер открывает TCP-сокет по адресу и порту из настроек и с заданным интервалом шлёт
  всем подключённым клиентам строку: измерение, координаты, углы взгляда первого игрока.
  Нужен внешним инструментам (камера-преследователь, стрим). Сокет принимает клиентов в
  отдельном потоке, отправка идёт в другом. Фаза: Ф6 (настройки и админ). План: нет. Код: нет.

## 3. `server/bossevents` — боссбары

- Кастомные боссбары (`/bossbar`), состояние сохраняется в отдельный файл мира. Фаза: Ф6.
  План: да (боссбары в Ф6). Код: частично (есть модуль, команда в работе).

## 4. `server/waypoints` — полоса локатора

- Игроки и точки интереса видны на полосе компаса вверху экрана. Сервер шлёт клиентам
  позицию, цвет и стиль значка, радиус видимости зависит от настроек мира. Фаза: Ф6
  (серверные части протокола). План: нет. Код: нет.

## 5. `server/rcon`, `server/notifications`, `server/jsonrpc`

- **RCON** и **query**: Ф6, план да. Код: частично.
- **Уведомления** (`server/notifications`): менеджер рассылает внешним сервисам события
  входа и выхода игрока, старт и остановку сервера, начало и конец сохранения, обновление
  мира, и «активность» с ограничением частоты (интервал в секундах из настроек). По
  умолчанию сервис пустой. Фаза: Ф6. План: нет. Код: нет.
- **Management API по JSON-RPC** (`server/jsonrpc`): второй сервер управления поверх
  websocket или TCP. Методы: allowlist и бан-листы (игроки и IP), операторы, игроки,
  игровые правила, настройки сервера, состояние сервера, discovery (список методов и схемы).
  Вход по секрету, режимы безопасности. Включается настройками с префиксом
  `management-server`. Фаза: Ф6 (параллельно с Ф8 API). План: нет. Код: нет.

## 6. `server/permissions` — уровни прав

- Уровни 0–4 и наборы прав. Проверка идёт через поставщика: уровень из `ops.json`, набор
  прав или объединение наборов. Фаза: Ф6, в плане уже есть LuckPerms-совместимость и
  `ops.json`. План: частично (нет модели поставщиков и объединения наборов). Код: частично.

## 7. `server/dialog` — диалоговые окна (26.x)

- Типы: уведомление, подтверждение, список кнопок, окно с несколькими действиями, список
  диалогов, список ссылок сервера. Внутри: текст, предметы, поля ввода (строка, число,
  флаг, выбор). Кнопки выполняют команду, открывают ссылку, копируют текст или шлют
  пользовательский payload. Команда `/dialog`. Фаза: Ф6 (протокол и команды); отображение
  у нас — Ф10. План: нет. Код: нет.

## 8. `server/dedicated` — настройки и сторож

- `server.properties`: много ключей, ванильные значения по умолчанию. Фаза: Ф6. План: да
  (совместимость с `server.properties`). Код: частично.
- Сторож (`max-tick-time`): план да (Ф6). Код: проверить.

## 9. `server/players` — списки игроков, сон

- **Сон.** Если спят все игроки (или заданная доля), ночь пропускается. Пока спят, идёт
  счётчик, есть сообщения. Кровать ставит точку возрождения. Фаза: Ф5c (время суток).
  План: нет. Код: нет.
- **Кэш ник → UUID** (`usercache.json`): размер и срок жизни записей ограничены. Нужен
  для команд по нику офлайн-игроков. Фаза: Ф6. План: нет (только баны и whitelist).
- **Конвертация старых списков**: ники в старом формате переводятся в UUID при первом
  запуске. Фаза: Ф6 (миры старых версий). План: нет.
- **Баны по IP**: план говорит про баны, но IP отдельно не назван. Фаза: Ф6. План:
  проверить. Код: проверить.

## 10. `server/packs` и `server/packs/repository` — паки

- Серверные ресурс-паки и их загрузка клиентами: очередь, кэш, очистка кэша по давности.
  Фаза: Ф6. План: частично (ресурс-пак есть, очистка кэша нет). Код: частично.
- **Оверлеи пакетов по версии**: один пак содержит варианты ресурсов для разных версий,
  выбирается по версии клиента. Фаза: Ф6. План: нет.
- **Флаги функций (экспериментальные)**: набор флагов мира и датапаков; сервер отказывает
  в запуске, если пак требует флаг, которого нет. Фаза: Ф6. План: нет. Код: нет.

## 11. `server/level` — загрузка чанков, игроки на сервере

- **Тикет-система загрузки чанков.** Разные типы тикетов (игрок, форс-загрузка, портал,
  спавн и т.д.) задают, какие чанки загружены и тикают. Расстояния view и simulation
  разделены. Фаза: Ф2 (чанки), форс-загрузка в Ф6. План: частично. Код: частично
  (есть форс-загрузка).
- **Поиск места возрождения**: ищет безопасное место рядом с кроватью или якорем, иначе
  спавн мира. Фаза: Ф5a. План: частично (возрождение на спавне есть). Код: проверить.
- **Демо-режим.** Фаза: Ф6, решение владельца (нужен ли). План: нет.
- **Режимы игры** (выживание, творчество, приключение, наблюдатель) и правила, что
  каждый режим разрешает. Фаза: Ф5a. План: частично (игрок в Ф5a). Код: проверить.

## 12. `server/network` и `server/network/config` — сеть и вход

- **Фильтр текста (text filter)**: внешний сервис помечает или прячет подписи, книги и
  чат; клиенту уходит отфильтрованный текст. Фаза: Ф6 (подписанный чат). План: частично
  (только «подписанный чат»). Код: нет.
- **Кодекс поведения** (code of conduct): конфигурационная фаза входа, игрок должен принять
  текст, иначе отключение. Фаза: Ф1 (вход). План: нет.
- **Старый ping списка серверов** (до 1.7) и legacy-запрос: в 26.3 не нужны, решить.
  Фаза: Ф6. План: нет.
- Подготовка спавна при входе, отправка чанков игроку, ресурс-пак в фазе конфигурации:
  есть в плане (Ф1, Ф2). Код: частично.

## 13. `server/commands` — команды, которых нет по поиску литералов

Соответствие «файл → команда» приблизительное: уточнять у команд-треков (сессии
`commands-*`). Список тех, что поиск не нашёл в `crates/mc-server` и `crates/mc-command`:
`/advancement`, `/attribute`, `/clear`, `/clone`, `/enchant`, `/loot`, `/list`,
`/ban-ip`, `/pardon-ip`, `/banlist`, `/deop`, `/save-all`, `/save-on`, `/save-off`,
`/setidletimeout`, `/spawnpoint`, `/teammsg`, `/transfer`, `/publish`, `/unpublish`,
`/dialog`, `/waypoint`, `/jfr`, `/perf`, `/debug` (несколько подкоманд отладки).
Фаза: Ф6 (команды), Ф5d (`/advancement`, `/loot`, `/enchant`, `/attribute`).
`/effect` и `/locate` в работе отдельной сессией.

## 14. `advancements` и `advancements/triggers`, `advancements/predicates`

- В плане Ф5d сказано «из данных», но сами триггеры не перечислены. Ванильных триггеров
  около пятидесяти. Главные группы: взаимодействие с блоком и предметом, использование
  предмета на месте, убийство с условием, стрельба (арбалет, стрела), вход в блок, падение
  после взрыва, ведро, рыбалка (крюк), удар молнии и канал молнии, крафт и открытие
  рецепта, лечение зомби-жителя, размножение животных, варка зелий, маяк, разрушение
  гнезда пчёл, смена измерения, эффекты изменились, левитация, зачарование, прочность,
  подбор, изменение инвентаря, спуск по блоку, таблица лута, призыв сущности, езда на
  сущности, урон игроку. Фаза: Ф5d. План: частично. Код: нет.
- **Предикаты** (условия) для достижений, лута и команд: 29 видов условий для сущностей,
  плюс условия предметов и блоков. Фаза: Ф5a (лут), Ф6 (датапаки). План: нет.

## 15. `stats` — статистика и книга рецептов

- Счётчики по категориям (блоки, предметы, мобы, движение), сохранение, форматирование
  значений, настройки книги рецептов. Фаза: Ф5d. План: да (`stats/<uuid>.json`, меню).
  Код: нет.

## 16. `world/entity` — сущности

### 16a. Поведение мобов (`ai`, ~100 поведений)

Ванильный «мозг» собирает поведения из набора задач. Задачи проверяют память и цель и
переключают состояние. Задач около ста, в плане есть только «Brain» и «жители, пиглины».
Пропущенные группы:

- **Деревня:** точки интереса (рабочие места, кровати, колокол), профессии (назначаются
  при занятии рабочего места, сбрасываются при его разрушении), поиск кровати, сбор у
  колокола и реакция на него, празднование после рейда, охрана.
- **Пиглины и варден:** бартер, пиглины атакуют без брони из золота, варден реагирует на
  вибрации и подкрадывается. Фаза: Ф5b.
- **Прочее:** панически убегают животные, следование за приманкой, ухаживание, разведение,
  игра с детьми, охота на цель, преследование с отступлением.
- Фаза: Ф5b. План: частично. Код: каркас целей (`mc-entity/src/mob.rs`: Float, Panic, Stroll, LookAtPlayer, Melee, Avoid, Swell, Leap, Bow, EatGrass; цели-мишени), A* (`nav.rs`), спавн/деспавн (`mc-server/src/mobs/`), виды: корова, овца, свинья, курица, зомби, скелет, крипер, паук. Нет: разведение, приманка, детёныши, сохранение мобов на диск, стрелы-снаряды, опыт.

### 16b. Жители, госсип, осады, торговцы (`ai/village`, `ai/gossip`, `npc`)

- **Госсип (слухи о репутации).** Жители обмениваются мнениями о игроках. Событие
  (например, атака жителя) даёт минус 25 к репутации, торговля даёт плюс 2. Записей
  хранится до 10 тем. Кулдаун разговора 1200 тиков. Старые записи угасают раз в 24000 тиков.
  Фаза: Ф5b. План: нет.
- **Железный голем.** Спавнится, если рядом (радиус 10) есть 5 жителей, которые согласны,
  и цикл сна прошёл. Фаза: Ф5b. План: нет.
- **Осады деревни** (`VillageSiege`): ночью деревня может позвать волну врагов, зависит от
  репутации. Фаза: Ф5c. План: нет.
- **Бродячий торговец**: спавн по таймеру в мире, состояние хранится в данных мира,
  исчезает по времени. Фаза: Ф5b. План: нет.
- **Торговля:** сделки, цены, пересчёт (ребаланс), обновление ассортимента по дням.
  Фаза: Ф5b. План: да («торговля»). Код: частично (есть торговый интерфейс, сделок нет).

### 16c. Рейды (`raid`)

- Константы, которых нет в плане: окно подготовки 300 тиков, таймаут 48000 тиков,
  максимум 2400 тиков без действий, 600 тиков празднования, поиск деревни в радиусе 96,
  эффект «предзнаменование рейда» до уровня 5, «герой деревни» на 48000 тиков. Волны и
  спавн: 5 попыток на точку, порог малого числа мобов 2 (смысл уточнить по коду). Фаза: Ф5c. План: да (без констант). Код: нет.

### 16d. Животные (`animal`) и мобы (`monster`)

- **Животные (около 30 видов):** пассивные и приручаемые (волк, кошка, лошадь, ослик,
  лама, попугай), водные (кальмар, дельфин, осьминог-аксолотль, черепаха, рыба), летающие
  (пчела с ульем и цветами), фермерские (панда, лиса, козёл, верблюд, сниффер,
  броненосец, лягушка), голем, голем-строитель. Для каждого вида своё поведение: приручение,
  седло, еда, размножение. Фаза: Ф5b. План: частично (размножение есть, видов нет).
- **Враждебные (около 22 видов):** крипер, зомби-варианты, скелет, паук, пиглин, зоглин,
  хоглин, ведьма, фантом (спавн при бессоннице, тесная связь со сном), брийз (ветровой
  заряд), скрипун (связь с сердцем скрипуна), вызыватель и остальные разбойники (illager),
  шулкер, эндермит, сильверфиш, гаст. Фаза: Ф5b. План: частично.
- **Варден** и его спавн (отдельный трекер): Ф5c. План: нет.

### 16e. Боссы (`boss`)

- **Дракон:** фазы, кристаллы, история полёта. Фаза: Ф5c. План: да (дракон). Код: нет.
- **Иссушитель:** фазы, взрыв, призыв. Фаза: Ф5c. План: да. Код: нет.

### 16f. Снаряды (`projectile`)

- Стрелы, трезубцы (если в 26.3), фейерверки (полёт на элитрах и обычные), эндер-жемчуг
  (телепорт), глаз эндера (указывает на крепость), плевок ламы, снаряд шулкера, клыки
  вызывателя, рыболовный крюк (прибивает, тянет). Фаза: Ф5a. План: нет. Код: нет.

### 16g. Транспорт (`vehicle`)

- Лодки и вагонетки (сундук, печь, спавн, рельсы). Лошади и прочие ездовые с седлом
  (сюда же). Фаза: Ф5a. План: да (вагонетки, лодки). Код: нет.

### 16h. Декоративные сущности (`decoration`)

- Рамки для карт (обычная и светящаяся), стойки для брони, картины, поводок и узел
  забора, манекен. Фаза: Ф5a. План: нет.

### 16i. Эффекты, атрибуты, еда, урон

- **Эффекты зелий** (около 20 видов): регенерация, отравление, иссушение, голод,
  насыщение, поглощение, левитация, «предзнаменование» (плохое и рейдовое), паутина,
  «ветряной заряд» и др. У каждого свой тик-эффект и категория (полезный или вредный).
  Фаза: Ф5a. План: частично (варка есть, эффекты нет). Код: частично (`effects` есть).
- **Атрибуты** (около 20): скорость, урон, броня, прыжок, дальность действия и т.д.
  Модификаторы складываются по двум способам (сложение и умножение). Фаза: Ф5a. План: нет.
- **Урон:** типы урона, масштабирование по сложности, сообщения о смерти по типу (упал,
  сгорел, утонул, убит игроком, убит мобом с именем), боевой трекер (история ударов,
  из которой собирается сообщение о смерти). Фаза: Ф5a. План: частично («урон»), сообщения нет.
- **Еда:** время поедания, сытость, насыщение (план есть). Компонентные эффекты еды
  (телепорт, снятие эффектов, звук) — Ф5a. План: нет.
- **Очки опыта (шары):** проверить по плану («опыт» есть). Код: проверить.

## 17. `world/item` — предметы, рецепты, зачарования

- **Компоненты предметов** (около 50 видов): инструмент, зелье, книги (писанная/пустая),
  фейерверки, карты, зарядка арбалета, еда (потребляемые), бандл, лоцман-компас, ульи в
  предметах, атрибуты предмета, описание (lore), кастомные данные. Это основа формата
  26.3. Фаза: Ф5a и Ф5d; в плане есть только точечно (еда, печи). План: частично.
- **Рецепты** (около 50 видов): крафт по форме и без формы, печи (плавка, коптилка,
  плавильная), кампфайр, кузнечный стол (шаблон, трансформация, отделка), ремонт, дубль
  щита и баннера, декорированный горшок, фейерверки, рецепт зелий, клонирование книги,
  карта-расширение, краска. Фаза: Ф5d. План: частично (рецепты из данных есть).

## 19. `world/level` — мир, блок-сущности, редстоун, время
